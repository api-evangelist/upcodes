# UpCodes

> UpCodes is a comprehensive compliance and product research platform for the construction industry — a searchable database of US construction and building codes consolidated by state and city, with libraries of codes, diagrams, and assemblies, project collaboration, code calculators (including a BIM design data import tool), and an AI Copilot for code compliance questions. UpCodes does not currently publish a public developer API.
